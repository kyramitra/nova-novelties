# Nova Novelties

A static, space-themed restaurant website for Kyra Mitra's imagined multi-cuisine restaurant.

## Local Preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://127.0.0.1:8000`.

## Source

The menu content is adapted from the provided Canva booklet, `Blue and White Playful Food Menu Cafe Booklet.pdf`.
